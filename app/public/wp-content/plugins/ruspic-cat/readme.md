# RUSPIC Cat v1.0

Независимый каталог товаров для WordPress без WooCommerce.

## Возможности v1.0
- Гибридная БД: WordPress для CMS/медиа/пользователей + собственные таблицы каталога.
- Бренды, категории, характеристики, товары.
- Дерево категорий.
- Поиск и фильтрация по бренду/категории.
- Собственная браузерная корзина на localStorage.
- Оформление корзины как заявки без онлайн-оплаты.
- REST API `ruspic/v1`.
- Админ-интерфейс RUSPIC Cat.
- WooCommerce не требуется.

## Установка
1. Загрузите ZIP через WordPress → Плагины → Добавить новый → Загрузить плагин.
2. Активируйте `RUSPIC Cat`.
3. Откройте меню `RUSPIC Cat`.
4. Создайте бренды, категории и характеристики.
5. Добавьте товары.
6. Создайте страницу каталога и вставьте `[ruspic_catalog]`.
7. Создайте страницу корзины и вставьте `[ruspic_cart]`.

## REST API
- `GET /wp-json/ruspic/v1/products`
- `GET /wp-json/ruspic/v1/products/{id}`
- `GET /wp-json/ruspic/v1/brands`
- `GET /wp-json/ruspic/v1/categories`
- `GET /wp-json/ruspic/v1/attributes`
- `POST /wp-json/ruspic/v1/orders`

## Архитектура
Каталог хранится в отдельных таблицах с префиксом `wp_ruspic_`. WordPress не заменяется и не модифицируется ядром. При удалении плагина таблицы не удаляются автоматически.
