# RUSPIC Cat v1.1

Независимый каталог товаров для WordPress без WooCommerce.

## Что нового в v1.1
- Переработана карточка товара по референсу RUSPIC: крупное фото, галерея, коды товара, наличие, цена, оптовый запрос и CTA.
- Добавлены вкладки «Описание и характеристики», «Вопросы», «Видеоматериалы».
- Характеристики оформлены компактными строками с разделителями.
- Карточки каталога получили изображения, статус наличия, более сильную типографику и B2B-иерархию.
- Добавлены адаптивные состояния для планшета и мобильного.
- REST API теперь возвращает `image_url`, `price_label` и `stock_label` для динамического обновления карточек.
- Улучшены quantity stepper, мини-галерея и feedback кнопки корзины.

## Установка
1. Обновите файлы плагина из `ruspic-cat-ui-patch-1.1.0.zip` или заберите актуальный `main` из репозитория.
2. Если плагин уже установлен, достаточно заменить 5 изменённых файлов из ZIP.
3. Очистите кэш страницы/плагинов после обновления.
4. Откройте товар через `[ruspic_product]` и проверьте карточку на desktop и mobile.

## Возможности
- Бренды, категории, характеристики, товары.
- Дерево категорий.
- Поиск и фильтрация по бренду/категории.
- Собственная браузерная корзина на localStorage.
- Оформление корзины как заявки без онлайн-оплаты.
- REST API `ruspic/v1`.
- Админ-интерфейс RUSPIC Cat.
- WooCommerce не требуется.

## REST API
- `GET /wp-json/ruspic/v1/products`
- `GET /wp-json/ruspic/v1/products/{id}`
- `GET /wp-json/ruspic/v1/brands`
- `GET /wp-json/ruspic/v1/categories`
- `GET /wp-json/ruspic/v1/attributes`
- `POST /wp-json/ruspic/v1/orders`
