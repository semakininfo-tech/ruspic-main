# Importaizer

Importaizer — отдельный WordPress-плагин для визуального импорта каталога поставщика в RUSPIC Cat.

## MVP 0.1.0

- анализ URL поставщика;
- безопасная проверка URL;
- обнаружение внутренних ссылок;
- поиск sitemap/robots.txt;
- обнаружение товарных URL по структуре;
- JSON-LD Product;
- HTML/D​​OM-разбор товара;
- SKU, бренд, цена, описание;
- таблицы характеристик;
- изображения;
- документы PDF/STEP/ZIP/DOC/XLS;
- визуальный предпросмотр до 10 товаров;
- импорт выбранных товаров в RUSPIC Cat;
- автоматическое создание брендов, категорий и характеристик;
- импорт изображений в медиатеку;
- журнал заданий и ошибок.

## Требования

- WordPress 6.6+
- PHP 8.1+
- RUSPIC Cat 1.0+

## Тестовый сценарий

1. Активировать RUSPIC Cat.
2. Активировать Importaizer.
3. Открыть Importaizer → Новый импорт.
4. Указать https://techelectro.ru.
5. Выполнить анализ.
6. Получить предпросмотр.
7. Импортировать выбранные товары сначала как черновики.
